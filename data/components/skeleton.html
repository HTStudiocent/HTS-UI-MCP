骨架屏

加载占位：skeleton-line / skeleton-avatar / skeleton-block 三种形状，呼吸动画尊重减少动效偏好。

HTML
<div class="skeleton skeleton-avatar"></div>
<div class="skeleton skeleton-line" style="width:60%"></div>
<div class="skeleton skeleton-block"></div>
<!-- 尺寸用行内 width/height 微调 -->
CSS
.skeleton {
    position: relative;
    background: var(--block);
    border-radius: 8px;
    animation: hts-skeleton 1.2s ease-in-out infinite;
}

@keyframes hts-skeleton {
    0%, 100% { opacity: 1; }
    50% { opacity: 0.45; }
}

.skeleton-line {
    height: 14px;
    margin-bottom: 10px;
}

.skeleton-avatar {
    width: 40px;
    height: 40px;
    border-radius: 50%;
}

.skeleton-block {
    height: 120px;
}
