提示条

三种强度：默认灰底、strong 左侧黑条、dark 黑底白字；.alert-title 起头加粗。

常规提示条：用于弱提醒。
重要提醒 左侧黑条强调，用于需要关注的说明。
强提示 黑底白字，用于最高优先级信息。
HTML
<div class="alert">常规提示</div>
<div class="alert strong"><span><span class="alert-title">重要</span> 说明文字</span></div>
<div class="alert dark"><span><span class="alert-title">强提示</span> 说明文字</span></div>
CSS
.alert {
    display: flex;
    gap: 10px;
    align-items: flex-start;
    border: 1px solid var(--border);
    border-radius: 10px;
    padding: 12px 16px;
    font-size: 13px;
    color: var(--text-soft);
    background: var(--block);
}

.alert .alert-title {
    font-weight: bold;
    color: var(--text);
}

.alert.strong {
    background: var(--surface);
    border-left: 3px solid var(--primary);
    border-radius: 0 10px 10px 0;
}

.alert.dark {
    background: var(--primary);
    border-color: var(--primary);
    color: var(--on-primary);
}

.alert.dark .alert-title {
    color: var(--on-primary);
}
