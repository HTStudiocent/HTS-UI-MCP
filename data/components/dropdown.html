下拉菜单

按钮带 dropdown-toggle，菜单为 dropdown-menu；点空白或按 ESC 自动关闭，同页多个互斥。

HTML
<div class="dropdown">
    <button class="btn btn-sm dropdown-toggle">操作 ▾</button>
    <div class="dropdown-menu">
        <button class="dropdown-item">编辑</button>
        <button class="dropdown-item">复制</button>
        <div class="dropdown-divider"></div>
        <button class="dropdown-item">删除</button>
    </div>
</div>
CSS
.dropdown {
    position: relative;
    display: inline-block;
}

.dropdown-menu {
    position: absolute;
    top: calc(100% + 6px);
    left: 0;
    min-width: 150px;
    background: var(--surface);
    border: 1px solid var(--border);
    border-radius: 10px;
    padding: 6px;
    box-shadow: 0 8px 24px var(--shadow);
    display: none;
    z-index: 20;
}

.dropdown.open .dropdown-menu {
    display: block;
}

.dropdown-item {
    display: block;
    width: 100%;
    text-align: left;
    padding: 8px 10px;
    font-size: 13px;
    border: none;
    background: transparent;
    border-radius: 7px;
    cursor: pointer;
    color: var(--text-soft);
}

.dropdown-item:hover {
    background: var(--block);
    color: var(--text);
}

.dropdown-divider {
    height: 1px;
    background: var(--border);
    margin: 6px 0;
}
