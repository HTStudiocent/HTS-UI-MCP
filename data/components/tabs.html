tabs-nav 里的按钮与 tabs-panel 按出现顺序一一对应，点击切换面板。

HTS UI：零依赖的黑白灰扁平组件库。
复制 dist/hts-ui.css 与 dist/hts-ui.js 到项目即可使用。
MIT License，可自由商用。
HTML
<div class="tabs">
    <div class="tabs-nav">
        <button class="active">简介</button>
        <button>安装</button>
        <button>许可</button>
    </div>
    <div class="tabs-panel active">面板一</div>
    <div class="tabs-panel">面板二</div>
    <div class="tabs-panel">面板三</div>
</div>
CSS
.tabs {
    border: 1px solid var(--border);
    border-radius: 12px;
    background: var(--surface);
    overflow: hidden;
}

.tabs-nav {
    display: flex;
    border-bottom: 1px solid var(--border);
    background: var(--block);
}

.tabs-nav button {
    padding: 10px 18px;
    font-size: 14px;
    border: none;
    background: transparent;
    color: var(--text-muted);
    cursor: pointer;
    border-bottom: 2px solid transparent;
}

.tabs-nav button:hover {
    color: var(--text);
}

.tabs-nav button.active {
    color: var(--primary);
    font-weight: bold;
    background: var(--surface);
    border-bottom-color: var(--primary);
}

.tabs-panel {
    display: none;
    padding: 18px 20px;
    font-size: 14px;
    color: var(--text-soft);
}

.tabs-panel.active {
    display: block;
}
